## Step: criteria

Your input lists the acceptance criteria and the tests artifact from the tests
step. For every criterion, read the code that implements it and decide PASS or
FAIL. Passing tests are evidence only for the behavior they actually assert;
read the tests to see what that is. Cite file and line when the evidence is in
code. The verdict is FAIL when any criterion fails.

Call submit_criteria once, with one entry per criterion ID.

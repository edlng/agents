# Stage 4 Team Lead Lab

This repository is a disposable evaluation fixture. The Litmus harness copies it
to a fresh isolated workspace before each case. Each directory is an independent
task; do not repair unrelated directories.

The lab intentionally uses only standard-library tooling:

- Node.js 20+
- Python 3.11+
- Go 1.22+

Run only the validator command named in the assigned task.
